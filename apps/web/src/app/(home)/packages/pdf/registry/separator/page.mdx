# Separator

Horizontal or vertical divider.

<ComponentPreview name="separator" height={360} />

## Installation

```bash
npx shadcn add https://ui-registry.com/r/pdf/separator.json
```

## Usage

```tsx
import { Separator } from "@/components/pdf/separator";

<Separator className="my-4" />

<Block className="h-10 flex-row gap-4">
  <Text>Left</Text>
  <Separator orientation="vertical" />
  <Text>Right</Text>
</Block>
```
