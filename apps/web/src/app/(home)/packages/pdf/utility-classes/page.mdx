# Utility Classes

Complete reference of supported Tailwind-style utility classes.

@ui-registries/pdf supports a subset of Tailwind CSS utilities, adapted for `@react-pdf/renderer`'s layout engine. All numeric values are in **PDF points (pt)** where 1 Tailwind unit = 3pt.

## Arbitrary Values

Any utility that accepts a numeric value also supports arbitrary values with `[...]`:

```tsx
<Block className="w-[210mm] h-[297mm]" />        {/* A4 page size */}
<Block className="p-[20]" />                       {/* 20pt padding */}
<Text className="text-[14]" />                     {/* 14pt font */}
<Text className="text-[12px]" />                   {/* 12px → 9pt */}
<Block className="aspect-[4/3]" />                 {/* 4:3 ratio */}
```

Plain numbers and `pt` values are points. `px` and `rem` are converted to points with the same ratio as the rest of the scale (1px = 0.75pt, 1rem = 12pt). Other units (`mm`, `cm`, `in`, `%`, `vw`, `vh`) are passed to react-pdf as-is.

## Spacing

Padding and margin utilities follow the standard Tailwind pattern. Negative values are supported with the `-` prefix (e.g. `-mt-2`).

### Padding

`p-{n}`, `px-{n}`, `py-{n}`, `pt-{n}`, `pr-{n}`, `pb-{n}`, `pl-{n}`

### Margin

`m-{n}`, `mx-{n}`, `my-{n}`, `mt-{n}`, `mr-{n}`, `mb-{n}`, `ml-{n}`

Auto margins: `m-auto`, `mx-auto` (center horizontally), `ml-auto` (push to the right in a row), etc.

### Gap

`gap-{n}`, `gap-x-{n}`, `gap-y-{n}`

## Sizing

### Size (width + height)

`size-{n}`, `size-full`, `size-auto`, `size-{fraction}` — sets both `width` and `height` to the same value.

### Width

`w-{n}`, `w-full`, `w-auto`, `w-{fraction}`

### Height

`h-{n}`, `h-full`, `h-auto`, `h-{fraction}`

### Min / Max

`min-w-{n}`, `max-w-{n}`, `max-w-full`, `max-w-none`, `min-h-{n}`, `max-h-{n}`

Fractions and `full` work with min/max variants too.

### Fractions

| Class | Value | Class | Value |
|-------|-------|-------|-------|
| `w-1/2` | 50% | `w-1/5` | 20% |
| `w-1/3` | 33.33% | `w-2/5` | 40% |
| `w-2/3` | 66.67% | `w-3/5` | 60% |
| `w-1/4` | 25% | `w-4/5` | 80% |
| `w-3/4` | 75% | `w-1/6` | 16.67% |
| | | `w-5/6` | 83.33% |

Twelfths (`1/12` through `11/12`) are also supported. All fractions work with `h-`, `basis-`, `min-w-`, `max-w-`, etc.

### Line Height

| Class | Value |
|-------|-------|
| `leading-none` | 1 |
| `leading-tight` | 1.25 |
| `leading-snug` | 1.375 |
| `leading-normal` | 1.5 |
| `leading-relaxed` | 1.625 |
| `leading-loose` | 2 |

Spacing scale (absolute, like Tailwind v4): `leading-6` → 18pt.

Arbitrary: `leading-[1.2]` (multiplier of the font size), `leading-[18px]` (absolute).

Multipliers behave like in CSS: they apply to the element's own font size, inherited or not, and a child with a different `text-*` size gets the same multiplier against its own size. A `text-2xl` heading inside a `text-sm leading-relaxed` page gets 1.625 × 24pt, not the page's line height.

### Letter Spacing

| Class | Value |
|-------|-------|
| `tracking-tighter` | -0.05em |
| `tracking-tight` | -0.025em |
| `tracking-normal` | 0em |
| `tracking-wide` | 0.025em |
| `tracking-wider` | 0.05em |
| `tracking-widest` | 0.1em |

`em` values are relative to the element's font size, like in Tailwind: `tracking-widest` on a `text-xs` label is narrower than on a heading.

Arbitrary: `tracking-[0.2em]`, `tracking-[2px]`, `tracking-[1.5]` (pt).

### Text Indent

`indent-{n}` — uses the spacing scale.

### Line Clamp

`line-clamp-{n}` — sets `maxLines` on the text element.

## Colors

Besides the Tailwind palette, the default theme has the shadcn/ui semantic tokens (`background`, `foreground`, `primary`, `muted`, `border`, `destructive`…) and a chart palette: `chart-1` to `chart-5`.

### SVG fill & stroke

| Class | Output |
|-------|--------|
| `fill-{color}` | `fill` (e.g. `fill-primary`, `fill-chart-1/50`) |
| `fill-none` | `fill: none` |
| `stroke-{color}` | `stroke` |
| `stroke-{n}`, `stroke-[1.5]` | `strokeWidth` |
| `stroke-none` | `stroke: none` |

They work on [SVG elements](/packages/pdf/svg) only.

### Background

`bg-{color}`, `bg-{color}/{opacity}`

### Text

`text-{color}`, `text-{color}/{opacity}`

### Border

`border-{color}`, `border-{color}/{opacity}`

### Alpha Modifier

Append `/{0-100}` to any color utility for alpha transparency:

```tsx
<Block className="bg-blue-500/50" />   {/* 50% opacity blue */}
<Text className="text-black/75" />     {/* 75% opacity black */}
```

### Arbitrary Colors

Use `[...]` for any color value:

```tsx
<Block className="bg-[#ff6600]" />
<Text className="text-[rgb(100,200,50)]" />
```

### Default Palette

The full Tailwind v4 color palette is included:

**Grays:** slate, gray, zinc, neutral, stone (50–950)

**Colors:** red, orange, amber, yellow, lime, green, emerald, teal, cyan, sky, blue, indigo, violet, purple, fuchsia, pink, rose (50–950)

**Special:** transparent, black, white

## Transforms

### Rotate

`rotate-{deg}` or `rotate-[30]` — value in degrees.

### Scale

`scale-{n}`, `scale-x-{n}`, `scale-y-{n}` — value as percentage (e.g. `scale-150` = 1.5x).

### Translate

`translate-x-{n}`, `translate-y-{n}` — uses the spacing scale, output in pt.

### Skew

`skew-x-{deg}`, `skew-y-{deg}` — value in degrees. Arbitrary: `skew-x-[15]`.

### Transform Origin

| Class | Value |
|-------|-------|
| `origin-center` | `center center` |
| `origin-top` | `center top` |
| `origin-top-right` | `right top` |
| `origin-right` | `right center` |
| `origin-bottom-right` | `right bottom` |
| `origin-bottom` | `center bottom` |
| `origin-bottom-left` | `left bottom` |
| `origin-left` | `left center` |
| `origin-top-left` | `left top` |

### Transform Composition

Multiple transform utilities are automatically composed into a single `transform` string:

```tsx
<Block className="rotate-45 scale-50" />
{/* → transform: "rotate(45deg) scale(0.5)" */}

<Block className="rotate-45 scale-50 translate-x-4" />
{/* → transform: "rotate(45deg) scale(0.5) translateX(12pt)" */}
```
